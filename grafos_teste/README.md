# Modelo de digrafo escrito em txt

### número de vertices
o número de vertices fica na primeira linha

### nome dos vertices
em seguida do número de vertices, cada linha representa o nome de um vertice

### conexões
em seguida dos nomes, cada linha representa uma conexão direcionada entre 2 vertices.
no padrão **[número]->[número]** onde os números representam os indices dos vertices.
o primeiro vertice é de onde o arco sai e o segundo vertice é para onde o arco vai.
