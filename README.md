### Funcionalidades

Para cada grafo em **grafos_teste/** que representa uma sequencia de tarefas, fazer:

- Detectar ciclos
- Produzir ordenações válidas
- Organizar a execução mais cedo possível de tarefas unitárias com processadores ilimitados

### Como rodar o código

1. [baixar make](https://gnuwin32.sourceforge.net/packages/make.htm) caso não tenha

2. baixar algum compilador de C caso não tenha

3. garantir que ambos estão no PATH (variavel de sistema) para que possam ser usados do terminal

4. abrir terminal dentro da pasta do projeto

5. escrever **make** no terminal

6. escrever **.\bin\main.exe** no terminal
